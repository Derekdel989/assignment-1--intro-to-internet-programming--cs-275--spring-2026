## ❖・Instructions・❖

Your task is to create a web site of Dieter Rams’s ten principles for good design. All ten are included in the accompanying file `ten-principles-for-good-design.txt`. You can create a single page site containing all ten rules, or a single site consisting of ten pages for each rule, plus the included `index.html` page. Your project *must* consist of the contents in the file `ten-principles-for-good-design.txt` and a navigation system, at the very least. Adding open source images is encouraged.

---

## ❖・Project Scaffold・❖

This repo contains a folder called `site`, which, in turn, contains some starter files for this project. (See the **File List** section below.) Before you start, replace `PUT YOUR NAME HERE` in the `title` element of `index.html` with your name, and replace `PUT YOUR GIHUB USERNAME HERE` with your GitHub username.

### File List

1. `README.md` — The document you’re currently reading. **Do not edit**
2. `ten-principles-for-good-design.txt` — The primary content you’ll use for this project
3. `site/css/reset.css` — **Do not edit**
4. `site/css/style.css` — All your CSS goes here
5. `site/index.html` — All your HTML goes here for a single-page site. For a multi-page site, `index.html` acts as the springboard to all the other HTML files you’d place inside the `site` folder
6. `site/img/` — Any images you use **must** go here. **Note**: All images **must** be smaller than 1MB

---

## ❖・The Rules・❖

* Only submit files that are required by your project; Do not submit working files, such as `.psd`, `.ai`, `.indd`, or `.sketch` files.
* Use lowercase, combined with kebab case, to name folders and files (`do-this` or `do-this.html`); no spaces in folder or file names (`not this`); no camel case (`notThis`); no snake case (`not_this`).
* Do not alter or remove the `reset.css` file in the `css` folder.
* Do not alter or remove any of the `.gitignore` files.
* You must use two typefaces. Look to [`https://fonts.google.com/`](https://fonts.google.com/) for ideas.
* You must use at least two colors, in addition to a neutral. Look to [`https://color.adobe.com/`](https://color.adobe.com/) for ideas.
* Your site’s UI must be logical, clear, and easy to use.
* For a multi-page implementation of this project, all your HTML files must go in the root of the `site` folder, with the `index.html` file acting as the springboard for your site.
* All your CSS must be placed in the `css` folder.
* Any images you might use must be placed in the `img` folder.
* Any images you include **must** be smaller than 1MB.
